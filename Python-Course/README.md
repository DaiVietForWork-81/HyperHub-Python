## 📖 Giới thiệu khóa học

Khóa học **Python-Course** là bộ giáo trình lập trình Python **hoàn chỉnh, có cấu trúc bài bản**, được biên soạn dành cho **học sinh, sinh viên và người hoàn toàn mới bắt đầu** lập trình.

Bộ giáo trình được xây dựng theo phong cách giảng dạy của một giáo viên thực thụ:

- ✅ **Giải thích cực kỳ dễ hiểu** — không giả định người học đã biết lập trình.
- ✅ **Ví dụ đời thực** — máy tính, ATM, quản lý học sinh, quản lý điểm, game, cửa hàng, thư viện...
- ✅ **Mỗi bài 3 file**: bài giảng 🎓 – bài tập 📝 – đáp án ✅.
- ✅ **20 bài tập mỗi bài** chia 3 mức: Dễ 🟢 – Trung bình 🟡 – Khó 🔴.
- ✅ **Đồ họa Markdown**: flowchart, bảng so sánh, mermaid, checklist, callout.
- ✅ **Sẵn sàng đăng lên GitHub** — mọi file viết bằng Markdown, tiếng Việt có dấu.

> 💡 **Khẩu hiệu:** *"Đừng chỉ đọc code — hãy viết code. Sai 100 lần vẫn tốt hơn nhìn đúng 100 lần."*

Sau khi hoàn thành khóa học, học viên sẽ:

- ✅ Nắm vững cú pháp và tư duy lập trình Python từ cơ bản đến nâng cao.

- ✅ Sử dụng được các cấu trúc: **biến, kiểu dữ liệu, toán tử, rẽ nhánh, vòng lặp, hàm, danh sách, từ điển, set, chuỗi**.

- ✅ Lập trình **hướng đối hướng đối tượng (OOP)**, **Dataclass**, **Decorator**, **Generator**.

## 🚦 Cách sử dụng

### Tự học

1. Đọc lần lượt từ bài 1 đến bài 41 **theo đúng thứ tự лі volume**.
2. Làm bài tập theo từng phần rồi so với đáp án.
3. Đừng nhìn đáp án trước — hãy **tự mình nghĩ ít nhất 15 phút** mỗi bài.
4. Mỗi tuần làm lại 1 bài khó nhất đã học để ghi nhớ lâu.

### Giảng dạy

- Dùng `bai_gi.md` làm **giáo án giảng dạy** trên lớp.
- Giao `bai_tap.md` làm **bài tập về nhà**, lưu đáp án làm tài liệu kiểm tra.
- Cuối mỗi chương có **검 tra nhanh** để chấm điểm tại lớp.

## 💻 Yêu cầu cài đặt

### 1. Cài đặt Python

> Xem hướng dẫn chi tiết: [Bài 2 – Cài đặt Python](02_Cai_dat_Python/bai_giang.md)

- Tải Python: [https://www.python.org/downloads/](https://www.python.org/downloads/)
- **Bắt buộc tích chọn** `Add Python to PATH` trong lúc cài đặt.
- Kiểm tra sau khi cài:

```bash
python --version
```

Kết quả mong đợi: `Python 3.9+` hoặc cao hơn.

### 2. Cài đặt Visual Studio Code

> Xem hướng dẫn chi tiết: [Bài 3 – Làm quen VSCode](03_VSCode/bai_giang.md)

- Tải miễn phí tại: [https://code.visualstudio.com/](https://code.visualstudio.com/)
- Cài **Extension Python** (Microsoft) trong marketplace để có gợi ý code, chạy, gỡ lỗi.

### 3. Chạy chương trình đầu tiên

Tạo file `hello.py` trong VSCode rồi bấm nút **Run** (▶️ góc phải) hoặc gõ:

```bash
python hello.py
```
